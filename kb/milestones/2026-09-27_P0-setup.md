## 5. What failed or surprised

- **The guard had a real gap** that the fault matrix exposed: a redirect to a quoted path was invisible.
  That was the only way to write into the workspace, whose name contains spaces. It was fixed and shown.
- **Agave 3.1.10, not the planned 4.3.0.** The first `anchor` command switched the active release,
  because Anchor 1.2.0 selects 3.1.10.
- **30 plugins, not 34.** The plan had counted generic plugins as Gubernaut's.
- **The Node pin.** `TOOLCHAIN.md` first claimed `/usr/bin/node` matched the pin. The doctor's fault
  run exposed that it does not.
- **Sensor v0 on a real clock** read fast legitimate payments as full intensity (still allowed).
