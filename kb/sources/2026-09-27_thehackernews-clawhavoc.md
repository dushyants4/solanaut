# ClawHavoc: malicious agent skills posing as Solana wallets

## Key facts

- **Scale:** 341 malicious skills out of 2,857 audited on ClawHub, the skill marketplace for the
  OpenClaw assistant.
- **What they stole:** exchange API keys, wallet private keys, SSH credentials and browser passwords.
- **The disguise:** the skills "masquerade as cryptocurrency trading automation tools", including
  "Solana wallets and wallet trackers".

## What it supports

- `docs/CLAIMS.md` M7
- [kb/wiki/defai/incidents.md](../wiki/defai/incidents.md): keys held by the agent's host are
  exposed to whatever the agent installs.

## Caveats

- Theft volume is not stated here. A "$2.3M" figure seen elsewhere is secondary and unverified; do
  not quote it.
