# The reference monitor

The classic definition of the component Solanaut aims to be for an agent's wallet.

## Key facts

- A reference monitor is "A set of design requirements on a reference validation mechanism that…
  enforces an access control policy over all subjects and objects."
- Its three requirements: it is "always invoked (i.e., complete mediation), tamperproof, and small
  enough to be subject to analysis and tests, the completeness of which can be assured (i.e.,
  verifiable)."
