## Where the plan moved, and why

- **Agave 3.1.10, not 4.3.0.** 4.3.0 installed first, as planned; then the first `anchor`
  command (even `anchor init --help`) ran Anza's installer and made 3.1.10 active: Anchor 1.2.0
  selects it. Pinned to what Anchor selects, proven with `anchor init` + `anchor build` on a
  throwaway program (an SBF `.so` and its LiteSVM tests). 4.3.0 stays installed, inactive.
- **The guard's quoted-redirect gap.** The Office's pattern refused any redirect target that
  starts with a quote. The Gubernaut workspace's path has spaces, so every shell write into it is
  quoted: the one write the policy exists to stop was invisible. Fixed and shown (above).
- **30 plugins, not 34.** The plan counted all enabled plugins; four are generic.
- **Node.** `/usr/bin/node` is 26.8.1; the pinned 26.7.0 comes from mise. `TOOLCHAIN.md` first
  said they matched; the doctor's fault run exposed it, and it was corrected.
- **Colosseum: only the approved text, and the link.** The editor also offers a repo-context box,
  the natural place for the rules' §9 disclosure. That would be new public text the human had
  not seen, so it was drafted in `docs/HACKATHON.md` instead of posted.

## The Colosseum text, as approved

- **Name:** Solanaut · **Category:** Security Tools · **GitHub:** https://github.com/dushyants4/solanaut
- **Description (432/500):** Solanaut is a transaction firewall for Solana AI agents. Before an
  agent's wallet signs, a deterministic policy (allowed programs, allowed destinations, spend
  caps) decides what it may sign, so a model tricked by a prompt injection still cannot pay an
  address you never allowed. An open-source control loop, Gubernaut Keel (Apache-2.0,
  pre-existing and disclosed), stops agents that keep retrying a failing transaction. Devnet only.
